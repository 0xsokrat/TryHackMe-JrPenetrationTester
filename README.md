# 🎯 TryHackMe - Jr Penetration Tester Path

Welcome to my personal study notes, lab writeups, and security cheat sheets for the **Junior Penetration Tester** learning path on [TryHackMe](https://tryhackme.com/path/outline/jrpenetrationtester).

This repository is maintained as a clean, lightweight **Obsidian Vault** designed for fast navigation, quick command reference, and structured security research.

---

## 📚 Covered Topics & Modules

- **Pentesting Fundamentals**: Engagement structure, reporting, and ethical hacking methodology.
- **Network Security**: Nmap live host discovery, port scanning, and protocol analysis.
- **Web Hacking Fundamentals**:
  - Burp Suite core workflows & proxy interception.
  - OWASP Top 10 concepts (SQLi, XSS, Command Injection, LFI/RFI).
  - Authentication bypass & HTTP request manipulation.
- **Privilege Escalation**: Linux & Windows privilege escalation basics and enumeration tactics.
- **Exploitation Concepts**: Metasploit Framework, payload construction, and shell handling.
